# Soul Family Tree Archive - v1.5 (2026)

## About This Report

This report documents the first major update to the family tree archive since its original publication. Version 1.5 reorganises the content into a dedicated, maintainable structure while preserving every family story, diagram, and source note exactly as written.

## What Changed

### New Organisation

- **One folder per family branch** - Each lineage now has its own section with a clear index page
- **Central index** - A main page links to every public family branch
- **Dedicated about page** - All contributors, sources, and permissions in one place
- **Shared resources** - Photographs and styles organised in common folders

### Privacy Improvements

- **Personal emails removed** - No email addresses appear on public pages
- **Protected contact** - Family contact handled through a secure form
- **Living members protected** - Details about living people excluded from public view
- **Verified sources required** - All corrections need family records or historical documents
- **Review before publish** - Every change reviewed by family before going live

### Technical Updates

- **Modern web standards** - Updated to HTML5 for long-term compatibility
- **Universal encoding** - UTF-8 throughout
- **Offline browsing** - Download and view the complete archive on any device
- **Relative links** - All navigation works without internet connection
- **Update dates visible** - Each page shows when it was last revised

### What Was Removed

- External search forms (relied on third-party services)
- Empty "notes" pages with no content
- Outdated contact information
- Proprietary formatting that prevented editing

### What Stayed the Same

- **Every word preserved** - Family stories, notes, and commentary unchanged
- **Original diagrams intact** - ASCII family tree charts with original spacing
- **All sources kept** - Manuscript references, bibliography, external links
- **Author's voice** - Grammar, phrasing, and style exactly as written
- **Historical dates** - Original publication dates preserved where available

## Why This Update Matters

The original website was built with tools that are no longer available (NetObjects Fusion) and formats that are difficult to maintain. This edition moves the archive to an open, standard format that:

- Can be edited with any text editor
- Tracks every change with full history
- Allows multiple family members to contribute
- Works reliably on modern and future devices
- Can be hosted anywhere (GitHub Pages, personal server, local computer)

## For Family Members

You don't need technical skills to use this archive:

- Browse online at the family domain
- Download a complete copy for offline reading
- Submit corrections through the issue tracker
- Request changes via the secure contact form

## For Contributors

If you're helping maintain the archive:

- All content in plain text files
- Standard folder structure
- Clear contribution guidelines
- Automated checks for common issues
- Full change history for accountability
