# Soul Family Tree Archive - v2 (2026)

## About This Report

This report documents the current 2026 state of the Soul family tree archive. It preserves all the original family history content while making it easier to navigate, share, and maintain for future generations.

## What You'll Find Here

- **Family branches** - Each family line has its own section with an index page
- **About & sources** - A dedicated page listing all contributors, sources, and permissions
- **Photographs & documents** - Images and scanned materials in a shared gallery
- **Works offline** - Download the entire archive and browse it on any device without internet

## Our Commitment to Accuracy

- All content, note, and lineage chart appears exactly as originally written
- All source references and historical citations are preserved
- Original ASCII family tree diagrams kept in their original format
- Last-updated dates shown on each page so you know what's current

## Privacy First

- No personal email addresses or contact details on public pages
- Living family members' information is not published
- Contact is handled through a secure, protected form
- All changes require verified sources (family records, historical documents)
- Every addition is reviewed before it goes live

## How This Edition Differs from the Original

| What | Original (2002–2019) | Current (2026) |
| --- | --- | --- |
| **Organisation** | Single website | Clear folders per family branch |
| **Editing tool** | NetObjects Fusion 7 (visual editor) | Any text editor |
| **Version control** | No built-in versioning | Git-based with full history |
| **Navigation** | Original links only | Main index + branch indexes |
| **Privacy** | Public contact info | Protected contact, living members excluded |
| **Collaboration** | Single author | Multiple family members can contribute |

- **No forks** - We maintain a single authoritative copy to avoid confusion

- **Domain redirects** - Your family domain points directly to the live archive
